## 01 · Sobre a experiência

A **Jornada de Conexões** é uma one-page autoral desenvolvida para apresentar minha trajetória no contexto do **Programa Estagiar Globo 2026 - 2º ciclo**.

Mais do que organizar experiências profissionais e acadêmicas, o projeto nasceu de uma pergunta:

**Como transformar uma trajetória multidisciplinar em uma experiência capaz de comunicar quem sou, o que me impulsiona e como posso contribuir?**

A resposta foi construir uma narrativa digital em que design, desenvolvimento e storytelling trabalham juntos.

Cada seção representa uma conexão entre experiências que, à primeira vista, podem parecer distantes: Artes Digitais, empreendedorismo, eSports, análise de dados, desenvolvimento Full Stack, UX/UI e inteligência artificial.

O fio condutor é o mesmo: **entender pessoas, conectar perspectivas e transformar ideias em experiências relevantes.**

## 02 · A jornada

A experiência foi concebida como uma narrativa contínua, organizada em quatro momentos.

| Capítulo | Experiência | O que comunica |
| :--- | :--- | :--- |
| **01 · Quem sou** | Identidade, mapa e repertório | Origens, formação, liderança e experiências que ampliaram meu olhar |
| **02 · O que me impulsiona** | D2B Gourmet e Junta-ai | A evolução do empreendedorismo e do branding para a construção de produtos digitais |
| **03 · Como posso contribuir** | Convergência de conhecimentos e processo de trabalho | Colaboração, criatividade, pensamento de produto e desenvolvimento centrado em pessoas |
| **04 · Histórias que se conectam** | Nuvem interativa e galerias de memórias | Experiências, referências e valores que fazem parte da minha trajetória |

### 01 - Quem sou

Uma apresentação que conecta identidade e geografia.

O percurso **Rio de Janeiro → Belo Horizonte → São Paulo** é representado por um mapa esquemático, enquanto experiências em eSports e no IBGE ajudam a contar como liderança, comunicação, dados e contato com diferentes realidades contribuíram para minha formação.

### 02 - O que me impulsiona

Duas experiências, diferentes momentos, uma mesma motivação.

**D2B Gourmet (2016–2019)**

Empreendedorismo, identidade visual, campanhas, relacionamento com clientes e construção de experiências de marca.

**Junta-ai (2026–atual)**

Desenvolvimento de um produto financeiro conversacional, conectando Product Ownership, liderança, frontend, UX/UI, APIs, engenharia de IA, qualidade e documentação.

A seção inclui uma galeria de registros da D2B Gourmet e uma demonstração ilustrativa do Junta-ai com dados fictícios.

### 03 - Como posso contribuir

Uma síntese de como diferentes conhecimentos se complementam.

Arte, branding e pessoas se conectam com dados, código e inteligência artificial.

O capítulo apresenta três perspectivas que orientam minha atuação:

- Repertório que atravessa áreas.
- Curiosidade que move ideias.
- Criatividade que vira construção.

O processo de trabalho é apresentado como um ciclo contínuo de aprendizado, colaboração e evolução, mantendo pessoas no centro das decisões.

### 04 - Histórias que se conectam

O encerramento transforma palavras em pontos de descoberta.

Uma composição tipográfica orgânica reúne **26 palavras e expressões**, combinando conceitos, experiências e referências pessoais.

Parte dessas palavras permite revelar galerias fotográficas relacionadas à trajetória apresentada.

A curadoria reúne:

**12 galerias · 35 imagens distintas · 37 associações fotográficas**

Entre os registros estão a Imersão Vem pra Globo, GloboSec Week, Estúdios Globo, Academia LED, Maratona de IA, Brand Session, esportes e outras conexões pessoais.

A experiência termina com uma reflexão sobre tecnologia, confiança e pessoas, seguida por uma assinatura SVG desenhada progressivamente quando a navegação chega ao final da página.

## 03 · Experiência e interatividade

A interface foi projetada para equilibrar narrativa, exploração e clareza visual.

| Recurso | Implementação |
| :--- | :--- |
| **Navegação por capítulos** | Âncoras e identificação da seção ativa |
| **Mapa de trajetória** | Representação SVG do percurso RJ–MG–SP |
| **Revelações progressivas** | Animações integradas à navegação |
| **Galerias de memórias** | Fotografias associadas às palavras interativas |
| **Interação multimodal** | Suporte a mouse, teclado e toque |
| **Galerias responsivas** | Navegação adaptada para dispositivos móveis |
| **Assinatura animada** | Desenho SVG acionado no encerramento da rolagem |
| **Movimento reduzido** | Respeito à preferência `prefers-reduced-motion` |

### Direção de arte

A identidade visual segue uma linguagem editorial, com fundo azul-marinho profundo, tipografia expressiva, contrastes claros e acentos em lilás e ciano.

A composição procura criar ritmo entre textos, imagens, espaços de respiro e elementos interativos, evitando que o movimento concorra com a mensagem.

**Princípio visual:** cada recurso precisa contribuir para a história, não apenas decorar a interface.

### Organização do conteúdo

`journey.js` centraliza os textos e os dados dos principais capítulos.

`connections.js` organiza as palavras, associações fotográficas e informações das galerias.

`memoryImages.js` auxilia no tratamento dos registros fotográficos.

Essa separação facilita a manutenção editorial sem exigir alterações diretas na composição dos componentes.

## 06 · Executar localmente

**Pré-requisitos:** Node.js 22.12 ou superior e npm.

Clone o repositório:

```bash
git clone https://github.com/danieli-dutra/via-dutra-conexoes.git
cd via-dutra-conexoes
```

Instale as dependências e inicie o ambiente de desenvolvimento:

```bash
npm ci
npm run dev
```

Para verificar o código e gerar uma versão de produção:

```bash
npm run lint
npm run build
npm run preview
```

O build de produção é gerado na pasta `dist/`.

## 07 · Responsividade e acessibilidade

O projeto considera diferentes formas de navegação e interação.

Entre os cuidados implementados estão:

- Estrutura semântica e navegação por âncoras.
- Link para pular diretamente ao conteúdo.
- Estados de foco visíveis.
- Interações por teclado, mouse e toque.
- Textos alternativos para imagens.
- Controles de navegação nas galerias.
- Suporte à preferência por movimento reduzido.
- Ajustes tipográficos para diferentes tamanhos de tela.
- Layout responsivo com atenção à legibilidade.

O desenvolvimento incluiu verificações automatizadas em Chromium, testes de rolagem, responsividade, interações e validações de lint e build.

Essas verificações representam os cenários testados, não uma certificação formal de acessibilidade.
